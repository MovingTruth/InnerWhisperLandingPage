プライバシーポリシー

発効日：2026年 • 対象：iOS 版 InnerWhisper

要点： InnerWhisper は個人データを収集・販売しません。データはデバイス上、または iCloud 利用時は Apple の仕組みを通じて個人アカウント内に残ります。Moving Truth はお気に入りや追加引用を受け取りません。任意の補足引用ファイルを HTTPS で別途取得することがありますが、アカウントやアプリ内容は含まれません。

1. 本ポリシーについて

本ポリシーは、InnerWhisper iOS アプリ利用時の情報の扱いを説明します。利用により、ここに記載した取扱いに同意したものとします。

私たちはプライバシーを重視します。Moving Truth がデータへアクセスできない設計で、データはデバイス上、または個人 iCloud を通じて Apple デバイス間だけを移動します。

2. 収集しない情報

InnerWhisper は次を収集、保存、送信しません：

  • 氏名、メールアドレス、その他の識別情報
  • あらゆる位置情報
  • アプリ内で扱う健康・ウェルネスデータ
  • デバイス識別子（IDFA、IDFV など）
  • 利用分析や行動データ
  • 当社サーバーへのクラッシュログや診断

利用にアカウントは不要です。Moving Truth は引用、お気に入り、設定、通知予定、その他の内容を受け取るサービスを運営しません。

InnerWhisper の Apple Privacy Manifest は NSPrivacyTracking: false Apple の要件に従い、収集データ種別を一つも記載していません。

3. デバイスに保存するデータ

次のデータをデバイスに保存します。お気に入りと追加した暗号化引用は、第4節のとおり個人 iCloud でも同期できます：

  • アプリ設定 — 通知予定、ビジュアルテーマ、引用コレクション設定。Apple の UserDefaults に保存され、ロック中は iOS Data Protection で保護
  • お気に入り一覧 — 保存した引用の ID。ローカル保存し、任意で iCloud 同期（第4節）
  • 暗号鍵 — iOS Keychain に保存し、デバイスのパスコードと Secure Enclave で保護
  • 引用ファイル — 統合引用ライブラリと追加引用。Keychain の鍵を用い AES-256-GCM で暗号化してアプリ領域に保存

引用ファイルは AES-256-GCM で暗号化します。設定は iOS Data Protection に依存します。Settings で暗号化をいつでも切替可能。無効時は iOS ファイル保護のみを使用します。アプリ削除でローカルデータはすべて消えます。

4. iCloud 同期

iCloud にサインインしている場合、2種類のデータを Apple デバイス間で同期します。すべて Apple の iCloud 基盤が処理し、Moving Truth は同期データを受け取るサービスを持ちません。

お気に入り（iCloud Key-Value Store）

  • お気に入り引用 ID は Apple の NSUbiquitousKeyValueStore API で同期します。
  • 同期するのは不透明な識別文字列のみ（例： 00000001-0000-4000-a000-000000000001）。引用本文や個人メモは含みません。

追加した引用（iCloud Documents）

  • 自作の引用は AES-256-GCM 暗号化ファイルとして個人 iCloud Documents コンテナ（iCloud.ca.imposterSyndromium.InnerWhisper）で同期します。
  • ファイルの暗号鍵は iCloud Keychain（synchronizable: true）で同期し、サインイン中の全デバイスで同じ鍵を利用できます。
  • 内容は iCloud 到達前に暗号化され、Apple も当社も平文を読めません。

Apple のプライバシーポリシー が iCloud 処理データに適用されます。InnerWhisper の iCloud 同期はいつでも次から無効にできます： iOS Settings → iCloud → Saved to iCloud → See All.

5. プッシュ通知

毎日の引用通知は ローカル通知として、iOS がデバイス上だけで予定・配信します。内容、予定、配信確認をサーバーへ送りません。

初回利用時に iOS が通知許可を求めることがあります。許可はいつでも次から取り消せます： 設定 → 通知 → Inner Whisper.

6. 第三者サービスなし

第三者の分析、広告、クラッシュ報告サービスと連携しません。具体的に、次を含みません：

  • 分析 SDK（Firebase Analytics、Amplitude、Mixpanel など）
  • 広告ネットワークや追跡ピクセル
  • クラッシュ報告や性能監視サービス

基本引用ライブラリはアプリに同梱。任意の補足引用ファイルを次から取得する場合があります： movingtruth.github.io/InnerWhisperQuotes 初回、キャッシュが24時間を超えたとき、または明示的な更新時に HTTPS で取得します。アカウント、広告識別子、トークン、引用、お気に入り、設定、その他の内容は含みません。HTTPS 配信には IP アドレス等の接続情報処理が必要ですが、Moving Truth は追跡やプロファイル作成に使いません。

7. 子どものプライバシー

13歳未満の子どもを対象としていません。子どもの個人情報を意図的に収集しません。提供されたと思われる場合は下記へご連絡ください。速やかに削除します。

8. データ保持と削除

すべてのデータはデバイスと個人 iCloud 内だけにあります。当社はアクセスできず、代理で削除できません。

  • ローカルデータの削除： デバイスから InnerWhisper を削除すると、iOS が関連データを自動削除します。
  • iCloud 同期のお気に入りを削除： アプリ削除後、次へ移動し 設定 → iCloud → 容量 表示される場合は InnerWhisper の iCloud データを削除します。

9. ポリシーの変更

本ポリシーを更新する場合、ページ上部の発効日を変更します。定期的にご確認ください。変更掲載後も利用を続けると、更新後のポリシーに同意したものとします。
