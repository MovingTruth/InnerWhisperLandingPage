InnerWhisper ← 홈으로 돌아가기

개인정보 처리방침

시행일: 2026년 • 적용: iOS용 InnerWhisper

요약: InnerWhisper는 개인정보를 수집하거나 판매하지 않습니다. 데이터는 기기 또는 iCloud 이용 시 Apple 시스템을 통한 개인 계정에 남습니다. Moving Truth는 즐겨찾기나 추가 명언을 받지 않습니다. 선택적 보충 명언 파일을 별도 HTTPS 요청으로 받을 수 있으나 앱 계정이나 내용은 담지 않습니다.

1. 이 방침에 관하여

이 방침은 InnerWhisper iOS 앱 사용 시 정보 처리 방식을 설명합니다. 앱 사용은 여기 적힌 관행에 동의함을 뜻합니다.

개인정보를 소중히 여깁니다. Moving Truth가 데이터에 접근할 수 없도록 설계했으며, 데이터는 기기나 개인 iCloud를 통한 Apple 기기 사이에만 남습니다.

2. 수집하지 않는 정보

InnerWhisper는 다음을 수집, 저장, 전송하지 않습니다:

  • 이름, 이메일 주소, 기타 식별 정보
  • 어떤 종류의 위치 데이터
  • 앱에서 접하는 건강 또는 웰빙 데이터
  • 기기 식별자(IDFA, IDFV 등)
  • 이용 분석이나 행동 데이터
  • 당사 서버로 보내는 충돌 로그나 진단

계정은 필요 없습니다. Moving Truth는 명언, 즐겨찾기, 설정, 알림 일정, 기타 내용을 받는 서비스를 운영하지 않습니다.

InnerWhisper의 Apple Privacy Manifest는 NSPrivacyTracking: false Apple 개인정보 요건에 따라 수집 데이터 유형을 하나도 기재하지 않습니다.

3. 기기에 저장하는 데이터

다음 데이터를 기기에 저장합니다. 즐겨찾기와 추가한 암호화 명언은 4절처럼 개인 iCloud로 동기화할 수 있습니다:

  • 앱 환경설정 — 알림 일정, 시각 테마, 명언 모음 설정. Apple의 UserDefaults 에 저장하며 기기 잠금 시 iOS Data Protection으로 보호
  • 즐겨찾기 목록 — 저장한 명언 ID. 로컬 보관하며 선택적으로 iCloud 동기화(4절)
  • 암호화 키 — iOS Keychain에 저장하고 기기 암호와 Secure Enclave로 보호
  • 명언 파일 — 통합 명언 라이브러리와 추가 명언. Keychain 키로 AES-256-GCM 암호화하여 앱 저장소에 보관

명언 파일은 AES-256-GCM으로 암호화합니다. 환경설정은 iOS Data Protection에 의존합니다. Settings에서 암호화를 언제든 켜고 끌 수 있으며, 끄면 iOS 파일 보호만 사용합니다. 앱 삭제 시 로컬 데이터가 모두 제거됩니다.

4. iCloud 동기화

iCloud에 로그인한 경우 두 유형의 데이터를 Apple 기기 사이에서 동기화합니다. Apple의 iCloud 기반이 전부 처리하며 Moving Truth는 동기화 데이터를 받지 않습니다.

즐겨찾기(iCloud Key-Value Store)

  • 즐겨찾기 명언 ID 목록은 Apple의 NSUbiquitousKeyValueStore API로 동기화합니다.
  • 불투명한 식별 문자열만 동기화합니다(예: 00000001-0000-4000-a000-000000000001). 명언 본문이나 개인 메모는 포함하지 않습니다.

추가한 명언(iCloud Documents)

  • 직접 쓴 명언은 AES-256-GCM 암호화 파일로 개인 iCloud Documents 컨테이너(iCloud.ca.imposterSyndromium.InnerWhisper)를 통해 동기화합니다.
  • 파일 암호화 키는 iCloud Keychain(synchronizable: true)으로 동기화되어 로그인한 모든 기기에서 같은 키를 쓸 수 있습니다.
  • 내용은 iCloud 도달 전에 암호화되며 Apple이나 당사가 평문으로 읽을 수 없습니다.

Apple 개인정보 처리방침 이 iCloud 처리 데이터에 적용됩니다. InnerWhisper iCloud 동기화는 언제든 다음에서 끌 수 있습니다: 설정 → iCloud → iCloud에 저장됨 → 모두 보기.

5. 푸시 알림

매일 명언 알림은 로컬 알림으로 iOS가 기기에서만 예약·전달합니다. 내용, 일정, 전달 확인을 서버로 보내지 않습니다.

첫 사용 시 iOS가 알림 권한을 요청할 수 있습니다. 언제든 다음에서 취소할 수 있습니다: 설정 → 알림 → InnerWhisper.

6. 제3자 서비스 없음

제3자 분석, 광고, 충돌 보고 서비스와 통합하지 않습니다. 구체적으로 다음이 없습니다:

  • 분석 SDK(Firebase Analytics, Amplitude, Mixpanel 등)
  • 광고 네트워크나 추적 픽셀
  • 충돌 보고나 성능 감시 서비스

핵심 명언 라이브러리는 앱에 포함됩니다. 선택적 보충 명언 파일을 다음에서 받을 수도 있습니다: movingtruth.github.io/InnerWhisperQuotes 첫 실행, 캐시가 24시간 넘었을 때, 명시적 업데이트 요청 시 HTTPS로 받습니다. 계정, 광고 식별자, 토큰, 명언, 즐겨찾기, 설정, 기타 내용을 포함하지 않습니다. HTTPS 전달에는 IP 주소 같은 연결 정보 처리가 필요하지만 Moving Truth는 추적이나 프로파일링에 쓰지 않습니다.

7. 아동 개인정보

13세 미만 아동을 대상으로 하지 않으며 아동 개인정보를 고의로 수집하지 않습니다. 제공되었다고 생각하면 아래로 연락해 주세요. 신속히 삭제합니다.

8. 데이터 보관과 삭제

모든 데이터는 기기와 개인 iCloud 계정에만 있습니다. 당사는 접근하거나 대신 삭제할 수 없습니다.

  • 로컬 데이터 삭제: 기기에서 InnerWhisper를 삭제하면 iOS가 관련 데이터를 자동 제거합니다.
  • iCloud 동기화 즐겨찾기 삭제: 앱 삭제 후 다음으로 이동하여 설정 → iCloud → 저장 공간 표시되면 InnerWhisper iCloud 데이터를 삭제하세요.

9. 방침 변경

이 방침을 갱신하면 페이지 위 시행일을 수정합니다. 정기적으로 확인해 주세요. 변경 게시 후 계속 사용하면 갱신 방침에 동의한 것입니다.
